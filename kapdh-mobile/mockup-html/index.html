Mockup HTML aplikasi KAPDH

Isi
52 halaman, 525 frame ponsel 360 x 800, 6 grup
Cakupan
48 dari 48 layar Flutter (47 *_screen.dart + AppShell), semuanya punya halaman
Sumber
kapdh-mobile/lib (Flutter 3.47.2, KapdhTheme.light())

Tiruan statis tampilan Flutter saat ini sebagai bahan iterasi desain. Setiap halaman berisi satu layar dengan semua keadaan pentingnya (utama, gulir penuh, kosong, galat, memuat, terkunci, dialog, lembar bawah) sebagai frame berlabel. Teks disalin dari Dart; data contoh fiktif. Buka lewat Chrome/Edge atau node tools/serve.mjs. Tombol di kanan atas mengganti tema gelap, teks 200 % dan tablet untuk semua layar (usulan v2).
