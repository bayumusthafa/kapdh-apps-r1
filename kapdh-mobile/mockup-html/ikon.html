Ikon premium: akses cepat dan navigasi bawah

Perbandingan empat set ikon pengganti Material Icons, digambar dengan komponen mockup asli (.quick-access, .bottom-nav dengan tab KTA tengah). Kriteria dari skill ui-ux-pro-max (references/pro-rules.md): satu keluarga ikon, tebal garis konsisten, disiplin outline untuk tab tidak aktif dan isi untuk tab aktif, kontras ikon minimal 3:1, ikon vektor yang bisa diberi warna token. SVG diambil sekali dari Iconify API dan ditanam di halaman ini (tanpa CDN). Arahkan kursor ke ubin dan tab untuk melihat state layer.

Terpasang Phosphor kini satu-satunya keluarga ikon di semua layar mockup dan aplikasi Flutter (akses cepat duotone, navigasi regular/fill, ikon lain regular/fill; ADR-027). Set Material di bawah hanya acuan.

Rekomendasi: Phosphor. Duotone untuk ubin akses cepat, Regular/Fill untuk navigasi. Set ini dikurasi skill ui-ux-pro-max, satu keluarga mencakup ketiga gaya, berlisensi MIT tanpa atribusi, dan duotone-nya satu warna sehingga hijau merek tetap dominan. Bila ingin kesan paling mewah, Solar Bold Duotone adalah pilihan kedua, dengan syarat atribusi CC BY 4.0. Iconsax tidak disertakan karena lisensi artwork-nya tidak dapat diverifikasi.
