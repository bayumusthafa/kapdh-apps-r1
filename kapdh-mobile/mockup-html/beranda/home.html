Beranda v2 (usulan): header zamrud bercincin emas, tab KTA tengah, banner dengan titik di dalam, akses cepat di atas banner dengan ikon fill bergradasi dalam lingkaran (ubin pertama Pesan menggantikan KTA karena KTA sudah ada di tab tengah; pada KTA tidak aktif/kedaluwarsa ubin KTA tetap karena Jejaring terkunci), kartu event berfooter, berita hero + baris ringkas, skeleton berbentuk Beranda. Diadaptasi dari NewDesign/home.html; rincian di REDESAIN.md.

Data contoh fiktif: anggota "Ahmad Fauzi" nomor 12.01.01.7, 3 belum dibaca, lencana Jejaring 2. Judul banner, event dan berita diambil dari draf docs/konten/konten-peluncuran.md; tanggal, lokasi dan harga contoh. Tidak ditampilkan: RefreshIndicator (tarik untuk menyegarkan), keadaan status lain "Beranda belum tersedia" (tanpa tombol; status di luar unverified/verified/expiring/expired tidak dapat membuka /home).
