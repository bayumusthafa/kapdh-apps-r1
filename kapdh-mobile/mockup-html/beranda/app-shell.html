Keadaan yang ditampilkan

  1. Anggota aktif
  2. KTA belum aktif: tab bergembok
  3. Lembar Event khusus anggota aktif (belum aktif)
  4. Lembar Event khusus anggota aktif (kedaluwarsa)
  5. Lembar Jejaring khusus anggota aktif
  6. Lembar status lain
  7. Varian bilah navigasi

Isi tab yang ditampilkan adalah Beranda (lihat beranda/home.html untuk semua keadaannya). Tab Event dan Jejaring khusus anggota aktif (bergembok) untuk status unverified dan expired; Beranda, KTA dan Akun selalu dapat dibuka. Garis atas DecoratedBox di Dart tertutup NavigationBar dan tidak digambar (terverifikasi golden). Pita Offline/Pemeliharaan dipasang per layar di bawah app bar, bukan di cangkang.
