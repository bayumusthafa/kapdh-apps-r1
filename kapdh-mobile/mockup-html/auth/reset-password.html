reset_token berlaku 10 menit; sisa waktu tampil bila jam server diketahui. Penghitung password: "n/8" merah di bawah 8 byte, "8/8" setelah minimum terpenuhi, "n/72" saat mendekati batas 72 byte (merah bila lewat). Tombol kembali judul dan tombol kembali sistem meminta konfirmasi selama izin masih berlaku.
