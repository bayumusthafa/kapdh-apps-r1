v2 (usulan): latar gradasi abu terang (--gradient-splash #FAFAFA → #E2E4E1) di mode terang, hijau tua surfaceDark (#0E280C) di mode gelap; judul, spinner, ikon dan tombol primary. Isi terpusat di dalam SafeArea. Gerbang aplikasi (GET /public/config) dan pemulihan sesi berjalan paralel; router berpindah sendiri saat keduanya siap. Saat "Coba lagi" ditekan, spinner tampil lagi (keadaan 1).
